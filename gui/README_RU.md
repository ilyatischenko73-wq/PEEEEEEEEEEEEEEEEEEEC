# PEEC Studio — отдельный интерфейс для Fortran

Интерфейс на Python/PySide6, трёхмерная визуализация PyVista/VTK,
графики Matplotlib. Расчёт выполняет отдельный **PeecSolverFortran.exe**;
исходное ядро C не требуется. GUI не нужно включать в проект Visual Studio.

## Windows: установка и запуск

1. Скачайте **ветку codex/fortran-port** целиком и распакуйте, например в `C:\PEEC`.
2. Соберите Fortran по [инструкции Windows](../fortran/WINDOWS_RU.md).
3. Установите 64-разрядный Python 3.12 с Python Launcher (`py`).
4. Откройте `gui\install_windows.bat`. Он создаст локальное окружение `.venv`
   и установит библиотеки из `gui/requirements.txt`. Нужен доступ к PyPI.
5. Запустите `gui\start_windows.bat`.
6. В окне укажите свой `PeecSolverFortran.exe`. По умолчанию используется
   `build\windows\PeecSolverFortran.exe`. Если собирали в Visual Studio,
   выберите EXE из её каталога x64/Debug или x64/Release.

Если решатель требует Intel DLL, запускайте `gui\start_windows.bat` из
Intel oneAPI command prompt либо установите соответствующие Intel runtimes.
Сам GUI может просматривать готовые результаты без установленного компилятора.
Для 3D нужен рабочий графический драйвер с поддержкой VTK/OpenGL.

Ручной запуск из корня проекта:

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r gui\requirements.txt
.venv\Scripts\python peec_gui.py
```

Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r gui/requirements.txt
.venv/bin/python peec_gui.py
```

## 1. Расчёт

Выберите информацию о сетке, рассеяние, ЭПР или один из трёх вариантов молнии.
Доступны выбор файлов сетки, параметры поля и поляризация, коэффициенты импульсов,
шаг и интервал времени, узлы, сопротивление шунта, геометрия щели, число потоков
и частота сохранения VTK. Параметры, не участвующие в задаче, отключены.

- **Импорт .cfg** загружает конфигурации из `cases/` или собственный файл.
  Относительные пути интерпретируются от указанного корня проекта, как у решателя.
  Координатные параметры `--strike`, `--return`, `--shunt-a/b` преобразуются
  в индексы ближайших узлов. Выходные пути из .cfg заменяются каталогом GUI.
- **Сохранить/открыть проект** сохраняет параметры и пути входных данных в JSON.
  Путь к EXE и каталог новых расчётов выбираются отдельно для текущего компьютера.
- **Экспорт .cfg** создаёт файл для запуска из Visual Studio или командной строки.
- **Запустить** проверяет основные параметры и создаёт уникальную папку
  `results/GUI/<дата_время>/`: `run.cfg`, `project.json`, `solver.log`, результаты.
  Глубокую проверку aperture-map и slot-cells выполняет сам Fortran-решатель;
  его сообщения отображаются в журнале.
- **Остановить** завершает запущенный процесс. Незавершённые результаты остаются
  в папке запуска; они не помечаются как успешный расчёт.

Для первой проверки: задача «Рассеяние», сетка `meshes/plate.msh`, частота 1e6 Гц.
Для существующих больших моделей удобно импортировать `cases/run_*.cfg`.
Параметры геометрии щели и номера узлов из шаблонов надо проверить для своей модели.
Физическая модель остаётся квазистатической; GUI не добавляет retarded-режим.

## 2. Сетка и узлы

Поддерживается формат решателя: ASCII Gmsh 4.1 с четырёхугольниками,
без параметрических и изолированных узлов.

1. Укажите нужные сетки на вкладке расчёта.
2. Нажмите «Показать сетку / выбрать узлы».
3. Выберите назначение: удар, возврат, шунт A или B.
4. Правой кнопкой мыши выберите вершину. Её индекс запишется в параметры.

Показываются **индекс Fortran с нуля**, исходный тег Gmsh и координаты.
Индексы сохраняют порядок чтения файла, не сортируются по тегам Gmsh.
Индекс можно задать вручную на вкладке параметров.

Для two-stage удар/возврат выбираются на **закрытой** сетке,
а шунт — на **открытой**. Для slot-cells все выводы относятся к открытой сетке.
Переключатель назначения автоматически выбирает соответствующую сетку.
Смена файла сетки требует повторной проверки ранее выбранных индексов.
Замкнутая модель closed не использует шунт — это ограничение решателя.

## 3. Поля результатов

«Открыть VTK» позволяет выбрать любой сохранённый файл:

- `*_surface*.vtk`: потенциал, заряд, плотность заряда;
- `*_edges*.vtk`: токи и вектор поверхностного тока;
- для гармонических результатов — Re, Im и модуль из соответствующих полей.

Выберите поле и цветовую карту, включите рёбра, задайте фиксированные пределы
цветовой шкалы. Для векторов доступны модуль, компоненты X/Y/Z и стрелки.
Стрелки нормированы по максимуму вектора: длина служит относительной иллюстрацией,
а численные значения поля сохраняют физические единицы. Как в приложенном
визуализаторе, отбрасываются векторы слабее 10% максимума.
Если рядом есть surface-файл, он отображается полупрозрачно вместе с рёбрами.

Для файлов с номерами кадров автоматически находится последовательность
**того же префикса**; ползунок и кнопка воспроизведения переключают кадры.
При сравнении кадров задайте фиксированную цветовую шкалу, иначе каждый кадр
масштабируется отдельно. Снимок 3D-вида сохраняется в PNG.

Исходный `visualize_peec_vtk.py` остаётся отдельным инструментом. В частности,
его анимация гармонической фазы и специальные наложения шунта доступны через
старый скрипт; новое GUI отображает сохранённые поля и временные кадры.

## 4. Графики для отчётов и статей

- **ЭПР из CSV**: `phi_deg`, `sigma_m2` (формат Fortran и C). Декартовы графики
  в м² или дБм², полярный график в м². В логарифмическом виде нули оставляют
  разрывы: искусственный порог и сглаживание не применяются.
- **Заданный импульс**: предварительный график двойной экспоненты
  `I(t)=K[exp(-ατ)-exp(-βτ)]`, `τ=t-delay`, ноль до задержки.
  K — коэффициент, а не пиковый ток. Используется интервал t-end из настроек.
  Для падающего импульса показывается E(t) в начале координат, в В/м.
- **Ток источника из CSV**: рассчитанные столбцы `time_s`, `source_A`.
  Для stage2 source_A означает половину суммы модулей токов связи, не ток молнии.
- **Ток шунта**: столбцы `time_s`, `shunt_current_A` из временного CSV Fortran
  либо `*_shunt_XXXXXX.dat` обоих решателей. При выборе DAT загружается
  последовательность того же префикса, без смешивания stage1 и stage2.
  CSV содержит все шаги, DAT — только сохранённые кадры.
  Выбирайте результаты расчёта с включённым шунтом; без шунта столбец CSV нулевой.

Подписи осей и заголовки — на русском, обозначения I, E, σ сохранены.
Шрифт DejaVu Serif поддерживает кириллицу. Можно изменить заголовок, масштабировать
график штатной панелью Matplotlib и сохранить **PDF/SVG** (вектор) или
**PNG 600 dpi**. Ток молнии и ток шунта строятся как отдельные графики.
ЭПР не пересчитывается из VTK: загружается именно результат вычисления ЭПР.

## Проверки

```sh
python -m unittest discover -s gui/tests -v
python -m gui.tests.smoke_gui
python -m gui.tests.solver_integration build/fortran/PeecSolverFortran
```

Последняя команда требует собранный Fortran. CI `.github/workflows/gui.yml`
проверяет модель данных и Qt на Windows/Linux, а взаимодействие с реальным
GNU Fortran — на Linux. Qt smoke-тест работает offscreen: он проверяет виджеты,
назначение узлов, VTK и процесс, но не гарантирует работу видеодрайвера пользователя.
Сборка Intel ifx в Visual Studio остаётся отдельной проверкой на вашем ПК.

Документация библиотек:
[Qt for Python](https://doc.qt.io/qtforpython-6/),
[PyVistaQt](https://qtdocs.pyvista.org/),
[Matplotlib](https://matplotlib.org/stable/).
